Eupub is an offline reader that displays EPUB, PDF and plain-text books in
"euspell", a reformed English spelling, and lets the reader switch between
reformed and original spelling while reading.

HOW TO TEST IT - PLEASE READ, THE APP NEEDS A BOOK
Eupub opens on a welcome screen with an "Open a book..." button. This is by
design, not an error: it is a reader, and it has no content of its own until you
give it a file. Nothing else will happen until a book is opened.

Any EPUB or PDF file on the test machine will do. If one is not to hand, a
public-domain EPUB can be downloaded from Project Gutenberg, for example
https://www.gutenberg.org/ebooks/1342 ("Pride and Prejudice", EPUB edition).
Save it, then use "Open a book..." and select it.

THE FEATURE TO LOOK AT
Once a book is open, the "euspell" checkbox in the toolbar switches the text
between reformed and original spelling, in place, keeping your position. That
single control is the product. With it on, "people thought they could read
through the rough night" appears as "peeple thoht they coodd read thruh the ruff
niht".

One intentional difference: a PDF is always displayed in reformed spelling,
because the conversion is applied once as the document is rendered. The
"euspell" checkbox is therefore deliberately disabled and greyed out while a PDF
is open. It is not an unresponsive control - it applies to EPUB and text books.

NO ACCOUNT, NO NETWORK
There is no account, no login, no credentials, no purchases and no
subscriptions, so there is nothing to provide for testing. The app makes no
network requests of any kind: no server, no backend, no analytics, no
advertising, no telemetry and no third-party SDKs. The 205,000-word lexicon that
performs the conversion is bundled inside the app. Nothing about the text ever
leaves the machine.

The app can be run with the network disconnected from first launch onwards,
which is the quickest way to confirm this.

INSTALLER BEHAVIOUR
- Per-user installation. It does not require administrator rights and does not
  elevate.
- It installs no drivers and registers no NT services, consistent with our
  product declaration.
- It is Authenticode-signed. The publisher is Kamran Ossia.
- Silent installation is supported with the /S switch, and /D=<absolute path>
  sets the target directory if required.
- It registers a file association for .epub, so EPUB files can be opened by
  double-clicking them.
- Requires Windows 10 or 11, 64-bit.
